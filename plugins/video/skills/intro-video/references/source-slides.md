# スライドを素材にする

スライドをページごとの画像にし、台本の時刻に合わせて Remotion で切り替える。スライドの見た目をそのまま使えるので、作り直すより早く、発表資料と動画の内容がずれない。

## ページ画像にする

1920×1080 の PNG にする。16:9 でないスライドは、余白を背景色で埋めて中央に置く（引き伸ばさない）。

| 形式 | 方法 |
|:--|:--|
| PDF | `pdftoppm -png -scale-to-x 1920 -scale-to-y -1 slides.pdf out/slide`、または pymupdf で 1920px 幅に描画 |
| Marp（`.md`） | `npx @marp-team/marp-cli slides.md --images png --image-scale 1.5`（解像度は `--image-scale` で調整）。日本語フォントと Chrome が要る |
| pptx | LibreOffice（`soffice --headless --convert-to pdf`）で PDF にしてから PDF と同じ手順。フォントの置き換えで折り返しが変わるので、ユーザーに PowerPoint から書き出した PDF をもらえるならその方がよい |
| Google Slides | 共有リンクが公開なら `https://docs.google.com/presentation/d/<ID>/export/pdf` を取得して PDF と同じ手順。非公開なら「ファイル > ダウンロード > PDF」で書き出してもらう |

画像は Remotion の `public/slides/01.png …` に置く。

書き出したら一覧（コンタクトシート）を作って見る。フォントの代替、絵文字の欠け、はみ出しは画像を見ないと分からない。

## 台本との対応

- 台本のシーン表に、区間ごとに映すページ番号を書く。1 ページを長く映しすぎると止まった映像に見えるので、10 秒を超えるページは、ゆっくりした拡大（Ken Burns）や、ページの一部を順に強調する演出を Remotion で足す。
- スライドのアニメーション（段階表示）は画像にすると消える。必要なら、段階ごとに別のページとして書き出すか、Remotion で該当部分を重ねて表示する。
- 発表者ノートがあれば、VO 原稿の下書きに使える。ただし話し言葉の発表と、字幕つきの動画とでは長さが違うので、キューの長さに合わせて詰める。
- スライドに小さい文字（出典、注釈）があるなら、動画では読めないことが多い。読ませたいものは VO か字幕で補う。

## Remotion での並べ方

`references/remotion.md` の `Footage` と同じように、区間ごとに `Sequence` を置き、中に `<Img src={staticFile("slides/03.png")} />` を入れる。切り替えは 0.3〜0.5 秒のクロスフェードを基本にし、話の区切り（章の変わり目）でだけ大きい切り替えを使う。台本のタイムラインと区間を一致させ、ページ番号と区間の対応表を `scripts.md` に残す。
