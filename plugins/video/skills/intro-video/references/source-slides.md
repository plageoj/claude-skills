# スライドを素材にする

スライドをページごとの画像にし、台本に合わせて Remotion で切り替える。

## 作り直す

ユーザーのスタイルで作り直してから動画にしたいと頼まれたら、そのスタイルを扱うスキルに任せる（ぺんたのスタイルなら presentation プラグインの `slide-create`）。なければ、作り直したスライドを用意してもらうか、そのまま使うかを訊く。slide-create で作り直したスライドのノートは、台本の文のあとに、スライドから削った文言が `元 pN:` の行で続く。VO の下敷きにするのは台本の文だけで、`元 pN:` の行は VO にも字幕にも入れない。尺が足りなければ、新しい話を足さずに `元 pN:` の行から戻す。

## ページ画像にする

1920×1080 の PNG を `public/slides/01.png …` に置く。16:9 でなければ `min(1920 / 幅, 1080 / 高さ)` 倍で描き、余白を背景色で埋めて中央に置く。

- PDF: pdftoppm か pymupdf。pptx は LibreOffice で PDF にする（PowerPoint で書き出した PDF をもらえればその方がよい）。Google Slides は `…/export/pdf`
- Marp: `npx @marp-team/marp-cli slides.md --no-stdin --html --allow-local-files --images png --image-scale 1.5`。位置を取る PDF は同じオプションで `--pdf --pdf-notes`
  - 画像は `<名前>.001.png` の形で出るので、`01.png` に改名する
  - `--no-stdin` がないと、エージェントのシェルでは標準入力を待って止まる
  - テーマが別の CSS（slide-create の `penta.css` など）なら `--theme-set <CSS>` も渡す。渡さないとテーマが外れ、段階表示で隠したものも見える

書き出したらコンタクトシートで、フォントの代替、絵文字の欠け、はみ出しを見る。

### 位置を PDF から取る

強調や寄りの位置は、画像を測らずに pymupdf で PDF から取る。行は `page.get_text("dict")`、箱などの図形は `page.get_drawings()` の `rect`。PDF の pt を 1920×1080 の px にする倍率（16:9 なら 1920 / ページの幅。PNG の `--image-scale` とは別）を掛け、16:9 でなければ余白のずれ（`(1920 - 幅 × 倍率) / 2` など）を足す。

- レイアウトを変えたら取り直す。前の値を使い回すと強調がずれる。
- 画像として貼られたグラフの線は PDF にない。PNG の画素から線の色を列ごとに拾い、上下の端の中点を 4px おきにつないで点列にし、静止画で重なるか確かめる。
- Windows で文字化けで落ちるなら `PYTHONIOENCODING=utf-8`。`python -I` では効かないので `sys.stdout.reconfigure(encoding="utf-8")`。

### 動画に出さないもの

会場向けの表示（撮影禁止のマーク、「その場で読んでね」の QR コードなど）と、ノートにある会場の聴衆に向けた発言（「今回は練習用のリポジトリを用意してあります」など、一人で動画を見る人には当てはまらない文）は、残すかを台本の段階で訊く。隠すなら背景色の矩形を Remotion で重ねる（画像は書き換えない）。

## 台本との対応

- ページは動かさず淡々とめくる。常にゆっくり拡大する（Ken Burns）と、端のロゴやあしらいが切れる。拡大は図や写真を見せる意図があるときだけ、台本の「画」の欄に書く。
- 発表者ノートは VO の下書きになる。注釈・出典など読ませない小さい文字は、VO にも字幕にも無理に入れない。話の中身に要るものだけを VO で補う。

## Remotion での並べ方

- **区間はキュー番号で決める**。ページごとに最初のキュー番号を持たせ、その開始の 0.5 秒前から次のページの開始まで。対応表を `scripts.md` に残す。
- **切り替え**は 0.3〜0.5 秒のクロスフェード、セクションの頭だけ 0.8 秒程度。後のページを上に重ねてフェードインさせ、前のページはフェードが終わるまで不透明のまま残す（区間の終わりで消すと、下地の上にフェードインする）。
- **強調**は `[最初のキュー, 最後のキュー, ページ, 矩形]` の表にし、行・パネル・箱を枠で囲む。
  - 枠は文字や箱の縁から 15px 前後離す。pymupdf の行の矩形は、縦は行間を含み、横は字の端ちょうどなので、15px は横に足し、縦は数 px にとどめる（縦にも足すと、隣の行やページ番号に重なる）。箱は中の文字ではなく図形の矩形で囲む（文字から取ると枠が箱の縁に重なる）。
  - 続くキューで同じ行なら 1 項目にまとめ、点滅させない。
  - 注釈・出典など読ませない文字（`.note` のような小さい文字）は強調しない。強調すると読ませることになる。
  - 形は枠 1 種類にそろえる。塗りと枠が混ざると違いに意味があるように見え、半透明の塗りは濃い箱の上で濁る。
  - 色はスライドで使っている色（主色の明度違いなど）から選ぶ。新しい色相は、スライドの配色の決まりを動画の側で破る。
- **強調は上から下へ一方向に進める**。上に戻ると「前に戻った」「読み飛ばした」ように見える。表を書いたら上に戻る箇所を探し、話す順が箇条書きと前後するなら前後する行をまとめて 1 つの枠にする（原稿を並べ替えるならユーザーに訊く）。まとめの一言で見出しに戻る所は、見出しを強調しない。意図した振り返りなら戻ってよいが、表にコメントを残す。
- **段階表示は声に合わせて出す**。前のページに何かを足しただけのページを 0.5 秒前にめくると、声より先に答えが見える。
  - そのページの区間は、足された部分を言うキューの頭＋0.1 秒（合成音声の頭の無音は約 0.18 秒）から始め、クロスフェードは 0.25 秒。
  - 足されたページで色が変わる行は、前のページで強調しておき、めくるまで出し続ける。
  - 前後のページで共通部分の位置がずれている（中央寄せのレイアウトで要素が増えたときなど）と、クロスフェードの間に二重に見える。ずれていたら、クロスフェードせずに切り替える。
  - `SLIDES` の項目に `reveal: true` のような印を持たせる。
- **スライドにない話は指し示す**。画面の文字は増やさない。
  - 問いや主張を受けて話が続く所、ページの結論を述べる所（ページの終わりまで）は、関係する行をまとめて枠で囲む。
  - 「だから」「つまり」は、スライドの矢印と次の行を囲む。下まで進んでから上に戻る指し示しは、このつなぎのキューに前倒しする。
  - グラフの推移は、寄ったあと折れ線を太い半透明の線でなぞる（`polyline` の `strokeDashoffset` を `interpolate` で動かす）。
- **寄り**: そのキューが終わってから 1.5 秒前後かけて、図の中心を `transformOrigin` にして `scale` を上げる。見出しが端で切れていないか静止画で確かめる。強調・なぞり・隠す矩形は、スライドと同じ拡大の中に置く。
- **字幕と重ねない**: 字幕あり版ではスライドを 86% に縮めて上に寄せ、下の帯（約 150px）に字幕を出す。2 行が収まるよう、字幕は 52〜56px、行の高さ 1.1 にする。帯と左右の余白は濃い色。字幕なし版は縮めない。
